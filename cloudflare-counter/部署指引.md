# 微信生态周报 · 访问计数器部署指引

目标：让全站所有人共享同一个真实增长的访问数字（跨设备一致），从 **1006 次 / 502 人** 起累加。

方案：Cloudflare Worker + KV（免费额度足够个人站用，国内访问快，数据你掌控）。

---

## 你需要准备
- 一个 Cloudflare 账号：https://dash.cloudflare.com/sign-up （邮箱即可，免费）

## 部署四步

### 第 1 步：创建 KV 命名空间
1. 登录 Cloudflare 控制台 → 左侧「Workers & Pages」旁边找到 **KV**（或搜 "KV"）
2. 点 **Create namespace**，名字填 `wechat-weekly-counter`
3. 创建后复制 **Namespace ID**（一串 32 位十六进制）

### 第 2 步：填入 Namespace ID
打开本目录的 `wrangler.toml`，把这行替换成你刚复制的 ID：
```
id = "REPLACE_WITH_YOUR_KV_NAMESPACE_ID"
```
改成：
```
id = "你的32位ID"
```

### 第 3 步：部署 Worker（二选一）

**方式 A · 网页控制台（不用装工具，推荐）**
1. 控制台 → **Workers & Pages** → **Create** → **Create Worker**
2. 名字填 `wechat-weekly-counter`，随便给段代码创建，然后点 **Edit code**
3. 清空编辑器，把 `worker.js` 的全部内容粘进去，保存（Deploy）
4. 回到 Worker 设置 → **Settings → Variables** → 在 **KV Namespaces** 里 **Add binding**：
   - Variable name 填 `COUNTER_KV`（必须完全一致）
   - KV namespace 选第 1 步建的 `wechat-weekly-counter`

**方式 B · 命令行（我帮你跑，需你授权登录）**
```bash
# 装 wrangler（仅一次）
npm install -g wrangler
# 登录（会弹浏览器，用你的 Cloudflare 账号授权）
wrangler login
# 部署（在 cloudflare-counter 目录下）
wrangler deploy
# 部署后绑定 KV
wrangler kv namespace create "COUNTER_KV"   # 若第1步已建则跳过，改用下面绑定
wrangler kv namespace bind "COUNTER_KV" --id 你的32位ID
```

### 第 4 步：拿到 Worker 地址，填回页面
1. 部署成功后，Worker 地址形如 `https://wechat-weekly-counter.<你的子域名>.workers.dev`
2. 在浏览器直接打开这个地址，应看到 `{"pv":1007,"uv":503,"isNewVisitor":true}` —— 说明成功
3. 把这个地址告诉我，我帮你填进页面 `build_html.js` 里的 `WORKER_URL` 常量，重新构建推送即可

## 计数规则（已写进 worker.js）
- **PV（已访问）**：每次有人打开页面 +1
- **UV（独立访客）**：同一「IP+匿名标识+浏览器」首次出现才 +1，重复访问不重复计
- **基数**：KV 首次计数时以 1006/502 起步（一旦开始计数就不再回退）
- 页面端：Worker 不可用时自动降级为本地累加，保证数字始终在动、页面不报错

## 安全说明
- Worker 只开放 GET，返回 JSON + 允许跨域（仅供你的页面读取）
- UV 指纹不含个人隐私，仅用于去重
